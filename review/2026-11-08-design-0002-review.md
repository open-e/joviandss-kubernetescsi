## 1. Verdict

The document is accurate in almost every code reference and number. Of about 90
file-and-line citations, two are imprecise and one is off by a line. The problems
are elsewhere: three statements are wrong at the edges, two testing requirements
cannot be met as the stages are ordered, and several items from the project review
land in files this design already edits, so the implementation would either fix
them for free or ship past them.

The items most likely to bite during implementation:

1. `go vet` would fail on every commit before the last one (B1).
2. Setup errors would become invisible until 0003 lands (B2).
3. The iSCSI baseline includes a fix that the 0002 build would not have (B3).
4. The NFS live cycle, a requirement, cannot run with today's tooling (B4).
5. A15 misses one Warn line that logs a request with `Secrets` (A6).

| A2 | Stage 4, A11, last paragraph | "Target names are already lower-case SHA-256 hex (`iscsi_driver.go:568`)" | The target name is `<prefix>:<hex>` (`iscsi_driver.go:569`); the prefix is the configurable `iscsi.iqn` (default `iqn.csi.2019-04`, `controllerplugin.go:168-171`).
